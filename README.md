# IT355-GroupProject1
Repository for our IT 355 Group Project 1

Database download step:
1. Download page for SQLite: https://sqlitebrowser.org/dl/#windows
2. Make sure the two .jar files are installed in the lib folder
3. In Explorer tab, under "Java Projects/IT355-GroupProject1/Referenced Libraries" make sure the two .jar file are listed there. If not, click the plus button and navigate to each file in the file explorer (they are both in the /lib folder)
